# KamranAshraf.com — Portfolio

My personal developer portfolio — a **Next.js + TypeScript** site with a terminal / cyberpunk aesthetic (matrix rain, glitch text, scanlines, animated counters).

## Develop

```bash
npm install
npm run dev      # http://localhost:3000
```

```bash
npm run build && npm start   # production
```

## Structure

- `app/` — Next.js app router (`layout.tsx`, `page.tsx`, `api/contact`)
- `components/sections/` — Hero, About, Services, Tools, Results, Testimonials, FAQ, Contact
- `components/ui/` — animated effects (MatrixRain, GlitchText, TerminalWindow, CursorGlow, …)
- `lib/` — utilities · `scripts/` — asset generation
